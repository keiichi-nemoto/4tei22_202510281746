## 1. ゴールと逆算KPI

10万人を「新規視聴 → 登録」の掛け算で分解し、毎月追う数字を決めます。

| フェーズ | 期間 | 登録者目標 | 月間再生数の目安 | 主な狙い |
| --- | --- | --- | --- | --- |
| ① 立ち上げ | 0〜3か月 | 1,000 | 3万 | 型を決める・収益化条件に近づく |
| ② 検索で積む | 4〜9か月 | 1万 | 30万 | 検索・関連動画からの流入を固定化 |
| ③ 拡散で伸ばす | 10〜15か月 | 5万 | 150万 | ショートとコラボで新規層を獲得 |
| ④ ブランド化 | 16〜18か月 | 10万 | 300万 | 「AIならこの人」の第一想起を取る |

毎週見る指標（YouTube Studio）:

- **CTR（クリック率）**: 5%以上。下回ったらサムネとタイトルを差し替え
- **平均視聴率**: 長尺で40%以上。冒頭30秒の離脱を最優先で改善
- **再生あたり登録率**: 1%以上。終盤の「次に見る動画」導線で改善
- **外部流入比率**: X・note・ブログからの流入を全体の10%以上

## 2. ターゲットとメッセージ

**メインターゲット**: AIを仕事に使いたいが、何から始めればいいかわからない会社員（20〜40代）

| 層 | 悩み | 届けるメッセージ |
| --- | --- | --- |
| 入門層 | ChatGPT以外の使い方がわからない | 「コードが書けなくても、AIに仕事を任せられる」 |
| 実践層 | Claude Code / Codex を試したが続かない | 「明日の業務でそのまま使える手順」 |
| 上級層 | エージェント・自動化を組みたい | 「実際に動かした構成と失敗談をすべて公開」 |

**一言で言うと（チャンネルの約束）**: 「会社員がAIで仕事を半分にする実験を、全部見せる」

## 4. チャネル別の広報施策

| チャネル | 役割 | 施策 | 頻度 |
| --- | --- | --- | --- |
| YouTube 長尺 | 本体 | 検索キーワードからタイトルを逆算。冒頭15秒で結論を言う | 週1 |
| YouTube ショート | 新規獲得 | 長尺の「一番驚く30秒」を切り出し、概要欄で長尺へ誘導 | 週3 |
| X（Twitter） | 拡散・信頼 | 動画1本を図解スレッド化。公開日に固定ポスト | 毎日 |
| note / ブログ | 検索・保存 | 動画の台本を記事化し、動画を埋め込む | 週1 |
| LINE / メルマガ | ファン化 | 新作通知と限定テンプレート配布 | 週1 |
| コラボ・登壇 | 信頼の借用 | 同規模AI系チャンネルと相互出演、勉強会登壇 | 月1 |

**1本の動画を7つに展開する流れ（ワンソース・マルチユース）**

1. 長尺動画を公開
2. ショート 3本に切り出し
3. X で図解スレッド
4. note 記事化
5. LINE で通知 + 特典配布
6. コミュニティ投稿でアンケート（次回ネタ集め）

## 6. 運用の仕組み

- **週次レビュー（30分）**: 上記4指標を記録し、改善を1つだけ決める
- **ネタ帳**: Obsidian に「検索キーワード / 視聴者コメント / ニュース」の3つの受け皿を作る
- **AIで省力化**: 台本の下書き、サムネ案、ナレーション（ElevenLabs）、切り抜きは AI に任せ、撮影と最終判断に時間を使う
- **炎上・誤情報対策**: 検証した日付とバージョンを動画内に表示。誤りは固定コメントで訂正
